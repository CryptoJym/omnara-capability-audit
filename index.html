04 / Reciprocal value

What is worth borrowing—or giving.

Lead recommendations after reviewing the independent audits. Effort bands are planning estimates, not quotations. Integration compatibility remains to be tested.

The smallest credible pilot.

After boundary hardening: one synthetic project, one Omnara agent, scoped BORG recall and a Plimsoll event adapter. Verify production egress compatibility first. Keep current production tasks in their native systems.

  1. Identity and scope: prove the agent can retrieve its project’s synthetic memory and cannot retrieve a second project’s.
  2. Recovery: interrupt, replay and reconnect; prove stable task/event IDs and no duplicate counted usage or accepted outcome.
  3. Evidence: retain source citations, unknown-cost fields, token categories and native completion receipts.
  4. Decision: compare recall quality, operator steps, recovery behavior and total cost against the current workflow. Expand only if the gain is demonstrated.

06 / Scope & evidence

Know what this establishes.

Source implementation, a passing targeted check and production acceptance are different claims. This report keeps those boundaries visible.

Frozen inputs

    What was exercised

    • A native memory query returned relevant candidate recall. BORG connector, memory and graph status reported PASS.
    • Graph ingestion watermark and last complete scan were unknown; liveness does not establish freshness.
    • 41 focused BORG connector tests passed: concurrency, process handoff and independent settings.
    • Selected Omnara tests did not run in the lead’s environment: required Go 1.27.1 versus installed 1.25.6. No provider sandboxes or full deployment were exercised.
    • Plimsoll’s native status command exceeded the bounded read deadline. Its paid cloud production readiness was not established.

    What is included in “My Systems”

    BORG supplies the connector and distribution. Memory supplies recall, graph, provenance and lifecycle machinery. Plimsoll supplies selective collection and work economics. Ecosystem means adjacent native conductors, fleet admission, Inbox and Beads; these are not automatically one public product.

    Plimsoll’s inspected working tree contained ongoing changes. Public commit links are supplied only where the cited file matches the pinned public revision. Installed and private source evidence is labeled accordingly.

    What remains unproven

    No penetration test, full load benchmark, fresh install comparison or end-to-end cross-product integration was performed. No causal productivity gain, exactly-once external effect or complete financial reconciliation is asserted.

    Omnara is Apache-2.0. BORG’s owner code is MIT, with separate dependency terms—including the FalkorDB engine’s SSPL distinction. Review the exact module and notices before redistributing a contribution. Private memory and private cloud source are excluded from the shared deliverables.

    Rating scale: 0 = no implementation found after scoped inspection; 1 = narrow prototype; 2 = partial with major limits; 3 = useful implementation; 4 = mature design with substantial coverage; 5 = comprehensive operational proof. Unknown is “?”, never 0. Evidence: live = directly observed bounded behavior; source = implementation inspected; documented = claim or design only; unknown = insufficient proof. No rating of 5 is justified by source alone.
