The decision, in plain language

Keep our strengths.
Improve how the work runs.

Omnara brings agents, recovery and an operator dashboard together. Our stack adds shared memory, control of our computers, and evidence of what the work delivered.

What do the labels and scores mean?

“My Systems” combines BORG, shared memory, Plimsoll and explicitly named adjacent fleet tools. These are separate components; a new BORG installation does not automatically include the full private estate. “Not found” means not found in the inspected scope, not proof that a feature is impossible.

Scores run from 0 to 5: 0 = no implementation found; 1 = narrow prototype; 2 = partial with major limits; 3 = useful implementation; 4 = mature design with substantial coverage; 5 = comprehensive operational proof. Unknown and not independently rated are never treated as zero. Importance uses the lead's criticality for the 24 common rows and Opus's for its two additional rows.

What is worth doing

A practical order of action.

Improve our foundation, borrow proven design patterns, then test the capabilities we could offer Omnara.

These are proposals. The audit did not implement these changes. Effort estimates describe small prototypes or repair scopes, not a complete integration.

The first integration should stay small.

One synthetic project, one Omnara agent, scoped memory and a Plimsoll event adapter. Verify project isolation, recovery and duplicate handling. Compare the result with our current workflow before expanding.

Outcome linkage

Grok emphasizes implemented joins. Opus emphasizes coverage and release gaps. Current completeness remains unknown.

Browser and desktop control

Some reviewers give shell and web tools partial credit. All found no built-in interactive UI controller in Omnara.

Privacy maturity

The systems collect different things. Selective capture, access controls and actual deletion are separate questions.

What was actually verified

  • 41 focused BORG tests passed. These covered concurrency, handoff and independent settings.
  • A live memory query returned relevant recall. Connector and graph status passed, but graph freshness remained unknown.
  • Selected Omnara tests did not run because the required Go version differed from the installed version.
  • Plimsoll's status read timed out. Current linkage coverage and production readiness were not established.
  • No full deployment, penetration test, cross-product pilot or causal productivity study was performed.
